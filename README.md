# 🚀 Taller de Programación Web

Este proyecto es la solución a la Evaluación 3 , implementada en **Python** con el framework **Flask**. La aplicación incluye un menú principal que enlaza a dos ejercicios de lógica y procesamiento de formularios.

---

## 🛠️ Requisitos y Ejecución

### Requisitos

* **Python 3.x**
* **Flask**

### Instalación

Se recomienda el uso de un entorno virtual (`venv`).

1.  **Clonar el repositorio:**
    ```bash
    git clone [https://github.com/Olealmendez/Evaluacion3_Oscar_Leal.git](https://github.com/Olealmendez/Evaluacion3_Oscar_Leal.git)
    cd Evaluacion3_Oscar_Leal
    ```

2.  **Activar el entorno virtual e instalar Flask:**
    ```bash
    # (Reemplazar 'source venv/bin/activate' por el comando de activación adecuado para tu OS)
    pip install Flask
    ```

### Iniciar la Aplicación

Ejecuta el servidor de Flask:

```bash
python main.py
